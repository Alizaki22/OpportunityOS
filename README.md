## Overview

OpportunityOS is a next-generation AI-powered platform that helps students, developers, creators, and builders discover opportunities such as internships, hackathons, scholarships, grants, jobs, and learning programs in one intelligent ecosystem.

The platform combines modern AI-driven discovery with Web3 identity and Solana-powered reputation systems to create a personalized and gamified career growth experience.

Instead of searching across multiple disconnected platforms, users can use OpportunityOS to discover curated opportunities, build a decentralized reputation, unlock achievements, and manage their growth journey from one mobile-first dashboard.

# ⚡ Installation

```bash
# Clone repository
 git clone https://github.com/yourusername/opportunityos.git

# Navigate to project
 cd opportunityos

# Install dependencies
 npm install

# Start development server
 npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file:

```env
VITE_SUPABASE_URL=your_url
VITE_SUPABASE_ANON_KEY=your_key
VITE_SOLANA_RPC_URL=your_rpc
VITE_ELEVENLABS_API_KEY=your_key
```
